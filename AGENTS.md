## Quran Lab SDK
This project uses Quran Lab's TajweedFormer SDK. Skill: https://sdk.quranlab.ai/skills/quranlab-sdk/SKILL.md, version 3.1.22, installed at .github/skills/quranlab-sdk/SKILL.md.
Before any change that touches the Quran Lab SDK, fetch https://api.quranlab.ai/v1/sdk/latest and compare the `version` of each platform this project uses (android, apple, web, c) with the version pinned in its build files. If a newer one exists, tell the developer in one line (version, `summary`, `severity`) and offer to upgrade as the skill's Update mode says; never upgrade without their yes. A `required` severity goes first, stated plainly.
The skill keeps itself current by one rule, its first section ("Before anything else"): at most once a day before work that touches the Quran Lab SDK, and at once when Quran Lab's API says `skill_version.outdated` or the developer asks, compare the version above with https://sdk.quranlab.ai/skills/quranlab-sdk/VERSION and, when that is newer, replace the skill at .github/skills/quranlab-sdk/SKILL.md from https://sdk.quranlab.ai/skills/quranlab-sdk/manifest.json (that address only, each file checked against its SHA-256), update this block, and tell the developer in one line. With a stored Quran Lab sign-in, GET https://api.quranlab.ai/v1/assistant/updates once per session also says whether a newer model version is available: tell the developer, change nothing without their yes (the skill's "The model the app is served").
